# 명운당 사주 (命運堂)

만세력 기반 사주팔자 풀이 + 오늘의 운세 웹앱. 다음 운세(fortune.daum.net/saju)의 정보 구조를 참고해, 전통 사주 분위기(밤하늘·한지·금박·낙관·오방색)로 디자인했다.

## 실행
`index.html`을 브라우저로 열면 된다. 빌드나 서버가 필요 없다.
(로컬 서버로 띄우려면 `python -m http.server 8000` 실행 후 http://localhost:8000)

## 구성
| 파일 | 역할 |
|---|---|
| `lib/lunar.js` | 만세력 라이브러리 (lunar-javascript 1.7.5, 절기·간지·대운 계산) |
| `js/saju.js` | 계산 엔진: 진태양시 보정, 사주 원국, 오행 비율, 십신, 신강/신약·용신, 신살, 대운, 인생 곡선 |
| `js/content.js` | 해석 문구 데이터 (일간 10종, 오행 강약, 십신 그룹, 신살, 궁합, 처방, 일진별 운세) |
| `js/persona.js` | MBTI 16유형·혈액형 4종 문구, 팩폭 문구, 사주↔MBTI 축 해설 (기본 `s` / 팩폭 `f` 두 가지 말투) |
| `js/app.js` | 화면 렌더링 (홈 → 입력 → 로딩 → 결과 탭) |
| `css/style.css` | 디자인 |

## 기능 추가: MBTI · 혈액형 · 팩폭 모드
- 입력 폼에서 MBTI(4축 토글)와 혈액형을 고를 수 있다. 둘 다 선택 항목이다.
- 결과의 '四 삼중 분석' 섹션: 통합 캐릭터, 사주로 본 MBTI와 싱크로율, 상황별(연애·일·돈·스트레스) 분석, MBTI·혈액형·용신 궁합.
- MBTI를 비워두면 사주의 오행·십신으로 MBTI를 추정해 보여준다.
- 결과 상단 토글로 '기본 풀이' ↔ '팩폭 모드'(친구 반말, 뼈 때리는 문장)를 바꾼다. 선택은 기기에 저장된다.

## 계산 기준
- 진태양시: 출생지 경도와 표준 자오선의 차이(1°=4분). 한국 서머타임(1948~60, 1987~88)과 UTC+8:30 시기(1908~11, 1954~61)를 자동 보정한다.
- 자시: 야자시 방식(23시대는 날짜를 유지).
- 오행 비율: 천간 1, 지지 1.2(지장간 비중 분배), 월지 2.0.
- 용신: 억부법을 단순화. 신강이면 식상·재성·관성 중 가장 약한 기운, 신약이면 인성·비겁 중 약한 기운.
- 대운 나이는 만 나이 기준.
- 사주로 본 MBTI: 십신 그룹 비율과 오행 비율로 각 축의 성향을 점수화했다 (예: 식상·재성·火가 많으면 E, 인성·水가 많으면 I). 재미용 추정이다.

검증: 1990.05.15 15:00 여성 예시를 다음 운세 결과와 비교했다. 원국 庚午·辛巳·庚辰·癸未, 대운 3세 庚辰부터 시작, 천을귀인 未, 괴강살, 용신 木, 황금기 50대 초반~60대 초반이 모두 같게 나온다.
